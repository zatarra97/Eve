# Account di prova

Creato durante il test nel browser del 23/10/2026 (`npm run dev`, http://localhost:5179).
Vive solo nel `localStorage` di quel browser.

| Campo    | Valore  |
|----------|---------|
| Username | prova   |
| Password | prova   |
| Username (2) | prova2 |
| Password (2) | prova  |

Si può eliminare dalla schermata di login (link "elimina" accanto all'account) e
ricreare con credenziali qualsiasi: un nome utente nuovo propone sempre la registrazione.
